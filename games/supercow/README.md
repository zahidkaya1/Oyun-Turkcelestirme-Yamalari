# SuperCow Türkçe Yama

## Dahil edilen yerelleştirme değişiklikleri

- `data/txt/tr/` altında 7 Türkçe dil dosyası, kullanıcının orijinal `data/txt/us/` dosyalarından delta ile üretilir.
- Menü ve oyun içi dil `tr` olarak seçilir.
- Kupa adları/açıklamaları Türkçeleştirilir.
- Görsele işlenmiş **START → BAŞLA**, **Spacebar → Boşluk**, **POLICE → POLİS**, **FARM → ÇİFTLİK** değişiklikleri uygulanır.
- `engine.exe` yalnızca doğrulanmış sürüm üzerinde delta ile yamalanır; yamalı executable repoda tutulmaz.
- Yenilenmiş sürümdeki giriş logosu atlama değişikliği de motor patch'inin parçasıdır.

## Bilerek dahil edilmeyenler

`gamelog.log`, internet kısayolları, kaldırıcı dosyalarının taşınması ve fazladan ikon kopyaları Türkçeleştirme için gerekli olmadığından yamaya dahil edilmemiştir.
